# MarketCore

MarketCore é um projeto de estudo em Java criado com a ideia de evoluir continuamente.

O objetivo é construir um sistema de e-commerce/marketplace cada vez mais completo, aplicando na prática os conteúdos que forem sendo aprendidos durante os estudos.

O projeto começou com conceitos básicos de Java e POO e está evoluindo para banco de dados, JDBC, arquitetura em camadas e, futuramente, tecnologias utilizadas no mercado.

---

## Objetivo do projeto

O MarketCore não foi criado para ser um projeto finalizado rapidamente.

A proposta é utilizar o mesmo sistema para estudar e implementar novas tecnologias ao longo do tempo.

Cada nova etapa adiciona funcionalidades, melhora a arquitetura ou substitui soluções mais simples por soluções mais próximas de aplicações reais.
